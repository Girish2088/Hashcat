# Hashcat Practical Labs

This folder contains the practical labs I performed while learning **Hashcat**.

The goal of these labs is not just to crack passwords, but to understand the complete workflow of password recovery—from identifying an unknown hash to selecting the correct attack method and recovering the original password.

Most of these labs are based on small, controlled examples so I can clearly understand what is happening before moving on to larger real-world scenarios.

---

# What Each Lab Contains

Every lab follows the same structure:

- Objective
- Commands Used
- Steps Performed
- Expected Output
- What I Observed
- What I Learned
- Screenshots

# What I'll Learn

By completing these practicals, I'll be able to:

- Identify common hash algorithms.
- Choose the correct Hashcat mode.
- Perform dictionary attacks.
- Recover passwords from different hash types.
- Crack multiple hashes in one session.
- Display recovered passwords without cracking again.
- Understand why wordlists are important.
- Compare CPU and GPU performance.
- Follow a complete password recovery workflow.

---

# Why I'm Doing These Labs

While learning Hashcat, I realized that simply remembering commands isn't enough.

These labs help me understand:

- How Hashcat actually works
- When to use a particular command
- How password recovery is performed during security assessments
- How to troubleshoot common problems while cracking hashes

The screenshots and notes are mainly for my own revision, but they also serve as proof that I've practiced the tool instead of only reading about it.
